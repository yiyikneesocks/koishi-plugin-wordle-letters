# @azulores/koishi-plugin-wordle-letters

[![npm](https://img.shields.io/npm/v/@azulores%2Fkoishi-plugin-wordle-letters?style=flat-square)](https://www.npmjs.com/package/@azulores%2Fkoishi-plugin-wordle-letters)

首字母猜词 (Wordle-Leiters): given 首字母 prefixes like ex/a/sp, guess words starting with them. Reduced guesses, same-prefix replay, and inflected forms as answers.

## Install

```
npm install @azulores/koishi-plugin-wordle-letters
```
